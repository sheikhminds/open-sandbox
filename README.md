# Open Sandbox

[![CI](https://github.com/sheikhminds/open-sandbox/actions/workflows/ci.yml/badge.svg)](https://github.com/sheikhminds/open-sandbox/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](./LICENSE)

Open Sandbox is a free and open-source, local-first chat interface built with
[Astryx](https://github.com/meta/astryx), React and StyleX (all MIT licensed).
Conversations are saved in the browser, and replies can come from the
[Reflection AI](https://www.reflection.ai/) OpenAI-compatible API.

## Setup

```bash
npm install
```

Copy `.env.example` to `.env` and add your token:

```bash
cp .env.example .env
# edit .env -> REFLECTION_API_KEY=your_token_here
```

The key is read **only by the server** (`server/chatApi.ts`). Vite loads it from
`.env` into `process.env` for the `/api/chat` proxy; because the variable is not
`VITE_`-prefixed, it is never included in the browser bundle. You can also
`export REFLECTION_API_KEY=...` in your shell instead of using `.env`.

Optional: `REFLECTION_MODEL` overrides the default `Beam-1.0-501B-A23B`.

## Features

- **Markdown replies** — headings, lists, tables, fenced code blocks with copy,
  inline code, links and emphasis, rendered by Astryx's `Markdown` component.
  Streaming replies parse incrementally and fade in chunk by chunk.
- **Conversation management** — new, rename, delete, search across titles *and*
  message bodies, export one or all conversations as `.md`, and clear everything.
- **Message tools** — copy, regenerate an assistant reply, edit and resend a user
  message, delete a single message, and inspect the model's reasoning in a
  collapsible panel.
- **Settings** — system prompt, temperature and max tokens, plus light/dark/
  system appearance. Saved locally with the conversations.
- **Keyboard shortcuts** — `⌘/Ctrl+K` new chat, `⌘/Ctrl+,` settings,
  `⌘/Ctrl+Shift+L` toggle theme.
- **Local-first** — conversations and preferences live in `localStorage`; no
  analytics, and the API token stays on the server.
- **Responsive on every device** — phones (≤768px) get a full-height `Drawer`
  with scrim, a compact chat density, a single overflow menu, short metadata and
  safe-area insets for notched screens; tablets (769–1024px) get a narrower
  docked panel; desktops get the full panel and all header actions. Short
  landscape viewports also switch to compact spacing. Astryx's `ChatLayout`
  supplies scroll-to-bottom and a keyboard-aware composer dock.

## Run

```bash
npm run dev      # http://localhost:5173
npm run build    # type-check + production build
npm run preview  # preview the production build (proxy still active)
```

If no key is configured the UI falls back to an offline demo responder, so the
interface is still fully usable.

## API

`POST /api/chat` accepts `{ "messages": [{ "role": "user", "content": "..." }] }`
and streams the OpenAI-style SSE response. `GET /api/chat` reports whether a key
is configured (boolean only — never the token).

The Beam models require the reasoning emitted with each earlier assistant turn,
so the client stores `reasoning_content` from every streamed reply and replays it
verbatim on subsequent turns. Turns without it (e.g. the seeded welcome or
local-demo replies) are omitted from the replayed history.
